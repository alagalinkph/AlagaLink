AlagaLink 2.0 — Bilingual Geriatric Health Education Website

CONTENTS
- index.html: website content and page sections
- styles.css: layout, colors, typography, responsive styling
- script.js: language switch, topic search/filter, health guide dialogs, sample tracker, and appointment demo
- group-photo.jpg: supplied BSN-3B group photo used in the About Us section

PREVIEW
Keep all four files in the same folder. Open index.html in a browser.
An internet connection is needed for the Google Fonts stylesheet. The website itself is static HTML/CSS/JavaScript.

PUBLISH WITH GITHUB PAGES
1. Extract this ZIP.
2. Open your public AlagaLink repository on GitHub.
3. Upload the CONTENTS of the AlagaLink_V2 folder into the repository root (not the folder itself).
4. Replace the old index.html, styles.css, and script.js when prompted. Upload group-photo.jpg as a new file.
5. Commit the changes.
6. Keep GitHub Pages set to Deploy from a branch, branch main, folder /(root).
7. Wait for deployment, then refresh your existing website URL.

IMPORTANT
This is an educational student prototype for NCM 114, Care of the Older Adults, Group B3. It is not a clinic, emergency service, secure medical-record system, or live telehealth service. The sample tracker and appointment request do not send information to the student group or book real appointments. Do not enter actual patient identifiers or sensitive health information. Health information is general and does not replace advice from a professional and licensed doctor or other qualified healthcare professional.

Contact details displayed on the site were supplied by the project team. Confirm the hotline's availability and email before public distribution.
